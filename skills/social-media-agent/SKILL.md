# Social Media Agent

## What this skill solves

Manage an X account end-to-end using browser automation, research, scheduling, and lightweight tracking.

## Use when

- The user wants to post on X/Twitter
- The user wants automated or repeatable X content workflows
- The user wants engagement tracking or reply workflows
- The user wants a native OpenClaw approach without external APIs

## Do not use when

- The user only wants a single manual tweet draft
- The task is for another social platform
- The user does not want automation or browser-based actions

## Inputs to ask for

Ask only for the minimum needed:
1. X handle or account context
2. Posting goal
3. Content topic or source material
4. Posting cadence

## Workflow

1. Research the topic or source material.
2. Draft the post or response.
3. Review for quality and brand fit.
4. Publish or schedule through browser automation.
5. Log what was posted and any engagement signals.

## Output requirements

Always include:
- Draft or action plan
- Posting angle or content pillar
- Quality or risk check
- Tracking note if posted

## Quality standards

- Keep posts authentic and platform-native
- Avoid spammy repetition
- Prefer clear, high-signal copy
- Respect rate and cadence limits

## Safety / constraints

- Do not post without user intent when the task is ambiguous
- Do not use generic filler engagement
- Do not rely on external APIs when native tools are sufficient
