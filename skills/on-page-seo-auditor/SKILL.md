# On-Page SEO Auditor

## What this skill solves

Find page-level SEO issues and turn them into a prioritized optimization plan.

## Use when

- The user wants an on-page SEO audit
- The page is not ranking and the content may be the issue
- The user wants a pre-publish SEO checklist
- The user wants to compare page SEO against competitors

## Do not use when

- The problem is mainly crawling, speed, or indexing
- The user wants keyword strategy from scratch
- The task is broad site architecture rather than page-level optimization

## Inputs to ask for

Ask only for the minimum needed:
1. Page URL or page content
2. Target keyword
3. Optional secondary keywords or competitor URLs

## Workflow

1. Gather the page and target query.
2. Audit title, description, headers, and keyword use.
3. Review content quality, internal links, and images.
4. Check page-level technical factors only as they affect on-page SEO.
5. Return a scored, prioritized recommendation set.

## Output requirements

Always include:
- Page summary
- Title tag findings
- Meta description findings
- Header structure findings
- Content and keyword findings
- Priority fixes

## Quality standards

- Be precise about what to change
- Keep recommendations tied to the target query
- Focus on the page, not the whole site
- Avoid generic SEO advice

## Safety / constraints

- Do not mix in deep technical crawl issues
- Do not invent scores when data is missing
- Label manual review versus automated findings
