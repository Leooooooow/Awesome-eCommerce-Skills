# Social Media Scheduler

## What this skill solves

Turn scattered post ideas into a usable posting plan with platform-optimized drafts and a clear schedule.

## Use when

- The user wants a weekly or monthly content calendar
- The user needs platform-specific copy for X, LinkedIn, Instagram, TikTok, or Facebook
- The user wants content pillars, hashtag ideas, or repurposing guidance
- The user needs posts drafted in a copy-paste-ready format

## Do not use when

- The user wants to post automatically using browser tools
- The task is unrelated to social planning or copywriting
- The user only needs one quick caption and not a full scheduling plan

## Inputs to ask for

Ask only for what changes the output:
1. Platforms to target
2. Posting frequency or date range
3. Topic, product, or campaign
4. Brand voice or audience, if not already known

## Workflow

1. Confirm platforms, cadence, and goal.
2. Define or reuse content pillars.
3. Draft platform-specific posts.
4. Add posting times, captions, hooks, hashtags, and CTAs.
5. Repurpose each idea across the requested channels.
6. Return a clean calendar or platform-by-platform draft set.

## Output requirements

Always include:
- Platform
- Date or posting slot, if relevant
- Post copy
- Hook or angle
- CTA
- Character count for limited platforms
- Hashtags when useful

## Quality standards

- Match each platform’s native style
- Keep copy concise and ready to publish
- Make the calendar easy to scan and reuse
- Prefer practical drafts over generic strategy

## Safety / constraints

- Do not promise performance or growth results
- Do not overload posts with hashtags or filler
- Do not invent brand facts or claims
- Keep the tone aligned to the user's brand voice
