# SEO Tools

## What this skill solves

Provide a broad SEO workbench for keyword research, content optimization, competitor review, and technical checks.

## Use when

- The user wants a general SEO skill instead of a narrow specialist
- The user needs keyword research or competitor SEO analysis
- The user wants content optimization or backlink review help
- The user wants a broad SEO checklist or starting point

## Do not use when

- The request clearly belongs to a specialized SEO skill
- The user only needs one narrow audit type, such as on-page or technical SEO
- The task is unrelated to SEO

## Inputs to ask for

Ask only for the minimum needed:
1. Target site or page
2. Primary keyword or topic
3. Goal: traffic, ranking, conversions, or audit

## Workflow

1. Clarify the SEO objective.
2. Choose the narrowest useful SEO subtask.
3. Gather the relevant inputs.
4. Run the check or analysis.
5. Return a prioritized recommendation list.

## Output requirements

Always include:
- The SEO task being handled
- The most important findings
- Priority recommendations
- Any missing data or limitations

## Quality standards

- Keep the scope clear
- Prefer actionable SEO advice over theory
- Avoid mixing unrelated SEO work into one response
- Use plain business language

## Safety / constraints

- Do not invent ranking data
- Do not claim tool access you do not have
- Route to a more specific skill when appropriate
