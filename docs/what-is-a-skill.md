# What Is a Skill?

A skill is a reusable workflow unit for a real job.

It is **not** just a prompt.

A good skill usually defines:
- the problem it solves
- when to use it
- the expected input
- the expected output
- the workflow steps
- the handoff to the next step
- the quality bar and risk boundaries

## Skills vs prompts

### Prompt
- one-off
- hard to maintain
- easy to lose context
- weak handoff structure

### Skill
- reusable
- easier to route
- easier for agents to inspect
- easier to compose into workflows
- more trustworthy when documented well

## Why ecommerce fits skills well

Ecommerce work has many repeatable workflows:
- content ideation
- hook testing
- creator outreach
- listing audits
- price diagnostics
- compliance rewrites
- analytics checks

These are better as skills than as random prompt snippets.
