# Installing Real Skills

This repository is not the primary install surface for production-ready skills.

## Use GitHub for
- reading skill docs
- checking metadata
- understanding workflows
- comparing categories
- helping humans and AI agents pick the right skill

## Use SkillHub / ClawHub for
- installation
- versioned distribution
- registry-based updates
- environment-specific delivery

## Recommended install policy

1. Try **SkillHub** first when available in your environment
2. Use **ClawHub** as the public fallback
3. Do not rely on manual GitHub file copying as the default install path

## Why

Registry-based installation is better because it supports:
- cleaner updates
- better version control
- safer distribution
- more reliable environment routing

GitHub should remain the public catalog and trust layer.
